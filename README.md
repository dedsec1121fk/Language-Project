# Language Project — English

<details>
<summary><strong>Full Termux Language Coverage & GitHub Language Balance</strong></summary>

Language Project now tracks **94 Termux programming/scripting language families and executable programmable DSLs** from the official Termux aarch64 package inventory snapshot used for this release. The 34 persistent workers remain the high-speed reversible chain; the additional 60 official Termux modules contain practical source, package metadata and on-device runtime detection. A module is never claimed as an active persistent worker until that protocol implementation passes real device verification.

```bash
language-project supported list
language-project supported status
language-project supported install-all
language-project supported balance
language-project supported audit
```

The repository contains `.gitattributes` plus a strict language-balance audit targeting **at least 0.2% for every tracked GitHub Linguist language group and at most 25% Python**. The packaged source is intentionally balanced with practical per-language Termux field guides and tools rather than hiding or relabeling Python. The current conservative local estimate keeps Python around **18–20%**, leaving headroom for GitHub Linguist heuristics. GitHub remains the final authority after push.

Everything downloaded, compiled or generated by Language Project continues to live under `$HOME/Language Project/`.

<summary><strong>Offline Human Language Vault — 8,276 Language Records + Unicode 17</strong></summary>

Language Project now bundles a separate **Human Language Vault** so ordinary language/script/Unicode work does not require a download after installation. The bundled snapshot contains **8,276 IANA language-subtag records**, **27,177 Glottolog 5.3 languoid rows** (families, languages and dialects), **174 Unicode Script property values**, **346 Unicode blocks**, expanded raw Unicode 17 reference tables, per-language/per-script JSON records, TSV indexes, and a prebuilt SQLite index.

```bash
language-project human status
language-project human languages greek
language-project human language el
language-project human scripts
language-project human script Greek
language-project human alphabet Greek --limit 100
language-project human detect-script --text "Hello κόσμε Привет مرحبا 你好"
language-project human glottolog-search Greek --level language
language-project human db-stats
```

The term **alphabet** is a convenience in the CLI: Unicode scripts also include abjads, abugidas, syllabaries, logographic systems and other writing systems. The IANA registry is a standardized tagging registry, not a census. Glottolog is bundled as a second, broader catalog layer for languoids; its data and CC BY 4.0 attribution are preserved under `data/human/glottolog/`.

Bundled source data lives under `data/human/`, including the Unicode license and the raw source files used to generate the indexes.

<summary><strong>Translation, Transliteration & Programming-Character Bridges</strong></summary>

Language Project now distinguishes **semantic translation** from **lossless text representation conversion**.

For semantic translation, a bundled exact glossary can translate supported common terms between its language packs without Internet access. Unknown text is preserved rather than guessed:

```bash
language-project human translation-status
language-project human translate --from en --to el --text "hello file success"
```

It deliberately does **not** claim perfect free-form machine translation for every living, historical, signed, constructed and low-resource language. Shipping that honestly would require enormous multilingual models and dictionaries.

For **any Unicode text**, including text from languages not present in the small semantic glossary, Language Project provides reversible conversions to and from programming-friendly representations:

```bash
language-project human encode codepoints --text "Γεια 👋"
language-project human encode unicode --text "Γεια 👋"
language-project human encode hex --text "Γεια 👋"
language-project human encode binary --text "Γεια"
language-project human decode codepoints "U+0393 U+03B5 U+03B9 U+03B1"
```

Supported bridges include Unicode code points, source-code escapes, UTF-8 hex, UTF-8 binary, decimal code points, HTML numeric entities, URL encoding and JSON escapes. The project can also emit source string literals for common programming languages:

```bash
language-project human source-literal rust --text "Γεια 👋"
language-project human source-literal javascript --text "κόσμε"
language-project human codepoint U+03BB
language-project human name-to-text "GREEK SMALL LETTER LAMDA | SPACE | LATIN CAPITAL LETTER A"
```

Programming punctuation/operators can also be narrated and parsed:

```bash
language-project human symbols-describe --text 'if (a >= b) { x++; }'
language-project human symbols-describe --locale el --text 'x += 1;'
language-project human symbols-parse --text '[open parenthesis]x[close parenthesis]'
```

English and Greek symbol narration is bundled. Other locales fall back to canonical operator names instead of inventing unreliable translations.

<summary><strong>Overview</strong></summary>

Language Project is a Termux-native polyglot execution platform, benchmark laboratory, practical file/integrity toolkit, and programming-language catalog. The repository keeps a strict distinction between **cataloged languages** and **languages that actually execute on the current Android device**.

- **94 Termux-supported language modules** in the dated official-package snapshot.
- **34 persistent reversible workers** used by the high-speed benchmark/polyglot chain.
- **60 additional native-language modules** with official package metadata, practical source and on-device runtime probes.
- **34 native practical tools** attached to the persistent worker tier.
- **1,327 bundled language/dialect catalog records**, refreshable from public indexes.
- Every executable language module contains its worker, native utility, metadata, usage documentation, deterministic example assets, and module verification metadata.
- Missing or broken runtimes are skipped instead of being falsely counted as working.

<summary><strong>Installation And Storage</strong></summary>

Run from the extracted repository in Termux:

```bash
bash install.sh
```

To also attempt installation of **all 94 registered Termux language families/toolchains** during the same installation:

```bash
bash install.sh --all-languages
```

The exhaustive option can use several GB because large toolchains are installed individually; normal installation keeps the verified worker core lean and you can add the full set later with `language-project supported install-all`.

The installer creates **one persistent project home** and keeps all generated state there:

```text
$HOME/Language Project/
├── app/          # installed repository/application source
├── build/        # compiled workers + compiled native tools
├── state/        # runtime verification, calibration, SQLite DB, checkpoints
├── results/      # benchmark/session results
├── bundles/      # portable session bundles
├── backups/      # project-created backups
├── reports/      # workspace/native-tool reports
├── logs/         # diagnostic logs
├── cache/        # regenerable cache
├── tmp/          # temporary working data
├── downloads/    # downloads created by Language Project
└── workspace/    # optional workspace
```

Useful commands after installation:

```bash
language-project
language-project home
language-project doctor
langtool list
language-project modules list
```

The short command `language-project-home` prints the persistent folder path.

# Language Project — Ελληνικά


<details>
<summary><strong>Πλήρης Κάλυψη Γλωσσών Termux & Ισορροπία Γλωσσών GitHub</strong></summary>

Το Language Project παρακολουθεί πλέον **94 οικογένειες γλωσσών προγραμματισμού/scripting και εκτελέσιμα programmable DSLs του Termux** από το snapshot του επίσημου Termux aarch64 package inventory που χρησιμοποιείται σε αυτή την έκδοση. Οι 34 persistent workers παραμένουν η γρήγορη reversible αλυσίδα, ενώ τα επιπλέον 60 επίσημα Termux modules περιέχουν πρακτικό source, package metadata και on-device runtime detection. Κανένα module δεν εμφανίζεται ως ενεργός persistent worker αν δεν περάσει πραγματικό verification στη συσκευή.

```bash
language-project supported list
language-project supported status
language-project supported install-all
language-project supported balance
language-project supported audit
```

Το repository εφαρμόζει αυστηρό έλεγχο ισορροπίας: **τουλάχιστον 0,2% για κάθε GitHub Linguist language group που μπορεί πραγματικά να εμφανίσει το GitHub και το πολύ 25% Python**. Η ισορροπία προκύπτει από πραγματικά εργαλεία και πρακτικά Termux field guides μέσα στα language modules, χωρίς να κρύβεται ή να μετονομάζεται ο Python κώδικας. Η συντηρητική τοπική εκτίμηση κρατά την Python περίπου στο **18–20%**, ώστε να υπάρχει περιθώριο για τις heuristics του GitHub Linguist.

Όλα τα downloads, builds, logs, reports και state αποθηκεύονται κάτω από `$HOME/Language Project/`.
