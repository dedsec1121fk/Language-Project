# Human Language Vault

Offline reference data and tools bundled with Language Project.

## Coverage layers

- **IANA Language Subtag Registry**: standardized language/script/region/variant identifiers and descriptions.
- **Glottolog 5.3**: bundled CLDF languoid table for families, languages and dialects.
- **Unicode 17.0**: character names, scripts, blocks, aliases, case folding, width, derived/core properties, bidi data, named sequences, normalization corrections and emoji properties/variation sequences.
- **Generated indexes**: JSON, TSV and SQLite for use without Python-specific APIs.
- **Translation bridge**: a deliberately scoped exact multilingual glossary plus universal reversible Unicode/programming representations.

The vault is designed for offline lookup and conversion. It does **not** claim that a finite bundled glossary is universal semantic machine translation.

See `PROVENANCE.json`, `glottolog/ATTRIBUTION.txt`, the bundled license files and `docs/human/`.
